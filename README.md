# Get Logical
Development prototype of a local Mac companion for accessible audio production.

Untested Logic Accessibility bridge and local Ollama preset metadata search. Not a release-ready app. Mac compilation, VoiceOver, real Logic interaction and offline privacy testing are required.

Manual GitHub Actions builds will create separate Apple Silicon and Intel development artifacts. Apps are ad-hoc signed, not notarized. No Apple signing secrets or local model is bundled. No license has been selected.

## Current development milestones

Hosted Audio Unit parameter editor and experimental mono pitch editor are included. The standalone app is a testbed. A Logic-native nested-plugin wrapper is a researched next milestone, not implemented yet. Mac builds compile and package on both architectures, but real Logic, VoiceOver and vocal-quality tests remain required. No production or audio-quality guarantee.
